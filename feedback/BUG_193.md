# 🟢 `[BUG-193]` Add "Create PR", "Unlink PR" button to VCS dashboard

- **Component**: `dashboard`
- **Created**: `2026-09-28 20:02:04 UTC`

#### Description

Add a "Create PR" button to the VCS dashboard. When clicked with one or more commits selected, it should create a PR for each commit and preserve commit ancestors information in Github. IT should validate the commit doesn't already have an associated PR. The "Unlink PR" button is the logical inverse of "Create PR".

#### Resolution Notes

1. Added `create_prs_for_commits(commit_hashes)` in `GitEngine` (`src/provider/vcs/git_engine.py`):
   - Validates that none of the selected commits already have an associated PR (raises `ValueError` otherwise).
   - Topologically sorts selected commits (ancestors before descendants).
   - Preserves commit ancestor information in GitHub by setting each descendant PR's base to its parent's PR branch (or repository default branch if root).
   - Generates PR branches (`pr<number>`) and records PR metadata and URLs.
2. Added `unlink_prs_for_commits(commit_hashes)` in `GitEngine`:
   - Validates that selected commits actually have associated PRs.
   - Deletes associated PR branches and tags to cleanly unlink commits.
3. Added `/api/pr/create` and `/api/pr/unlink` REST API endpoints in `src/provider/dashboard/server.py`.
4. Added `#btnCreatePR` and `#btnUnlinkPR` buttons to the Smartlog column header in `src/provider/templates/diff_view.html.j2` with client-side controllers `onCreatePR()` and `onUnlinkPR()`.
5. Added comprehensive regression tests in `test_regression_bug_193_create_and_unlink_pr_buttons_and_ancestors` in `src/tests/test_dashboard.py`.
