- **Status**: `RESOLVED`
- **Severity**: `MEDIUM`

- **Component**: `diff_view, dashboard`

#### Description

Update the dashboard/diff view with a modal commit UI which, and graft an amend button to the existing main toolbar UI. Allow individual files to be selected or deselected for commit and amend. Add icons to discard selected tracked or untracked changes which haven't been committed.

#### Resolution

1. Added `commit_files`, `get_head_commit_message`, and robust `discard_files` methods to `GitEngine` in `src/provider/vcs/git_engine.py`, supporting selective file staging, commit amending, and safe discarding of staged, unstaged, untracked, and deleted files.
2. Added `/api/head_commit_message`, `/api/amend`, and extended `/api/commit` and `/api/discard` in `src/provider/dashboard/server.py` to handle selective file lists and amend workflows.
3. Enhanced HUD UI in `src/provider/templates/diff_view.html.j2`:
   - Grafted `[+ Commit]` and `[⎇ Amend]` action buttons to the main toolbar.
   - Added modal commit/amend overlay with select-all toggle, individual file checkboxes, commit message textarea (prefilled with HEAD commit message when amending), and file discard action buttons.
   - Added individual selection checkboxes and discard buttons to the "Changed Files" list.
4. Added comprehensive regression tests in `src/tests/test_dashboard.py` verifying selective commit, amend, discard, and REST API endpoints.
