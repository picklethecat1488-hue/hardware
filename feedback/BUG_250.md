#### Description

┃   The u-blox NINA-B312 module is based on the Nordic Semiconductor nRF52840 SoC, which features an
 ┃   integrated NFC-A Type 2 / Type 4 Tag peripheral with hardware touch-to-wake support.
 ┃ 
 ┃   • Hardware Requirements:
 ┃       • Route the NFC1 and NFC2 pins from the NINA-B312 module footprint to an external 13.56 MHz tuned coil
 ┃       antenna.
 ┃       • Place two external tuning shunt capacitors (C_{tune1}, C_{tune2}, typically 180--330 pF NPO/C0G)
 ┃       across NFC1/NFC2 to match the target antenna loop inductance to resonance at 13.56 MHz (f =
 ┃       1/(2π√(L_{ant}C_{tot}))).
 ┃   • Pros: Zero additional active ICs, zero added quiescent current, and native Nordic SDK / Zephyr / Embassy
 ┃   firmware driver support.

#### Resolution Notes

Routed native nRF52840 NFC1/NFC2 from U11 (NINA-B312) to external tuned coil antenna header J16 with 300pF C0G shunt tuning capacitors C18 and C19, achieving 0 DRC violations.
