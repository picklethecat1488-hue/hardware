#### Resolution Notes

1. Updated `verify_signal_lines_isolation` in `src/provider/simulation/flying_probe.py` to accept `subassembly: Optional[str] = None` and return empty isolation checks when inspecting `flex_tail`, as the flexible tail lacks opposing test pads or local DC power/ground reference test points for galvanic isolation probing.
2. Updated `create_flying_probe_hooks` in `src/provider/simulation/flying_probe.py` to pass `subassembly=target_label` and filter `board_comp_names` so that `flex_tail` simulation only loads test steps explicitly defined for `flex_tail` in `pcb_test_steps.yaml` (7 capacitive and continuity steps), omitting nonexistent `TEST_ISO_*` steps.
3. Verified `render_markdown_test_report` omits the `Signal Line Isolation Audit` section when `isolation_checks` is empty, while correctly rendering `Mutual Capacitance Touch Simulation & Verification (Flex Tail)`.
4. Added automated regression unit test `test_regression_bug_220_flex_tail_flying_probe_isolation_excluded` in `src/projects/tests/test_carrier_board.py`.
