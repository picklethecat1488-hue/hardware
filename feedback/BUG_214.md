- **Severity**: `LOW`

#### Description

-Remove the PCIe connector and cutout from the design, there is no use case for it.
-Add support for BTLE to function as a UART connected to U1
-Minimum speed: 1Mb/s
-Support pairing by a cap touch input gesture, or proximity-based pairing (similar to AirPods)
-Antennae should be built into PCB, an external antenna is acceptable if required by design constraints. If we are adding an external antenna, the enclosure needs to be modified with an antenna mount
-Main user LED and piezo buzzer will provide the BTLE connection status information
-Bluetooth logo should be visible on the enclosure cover
-Ensure PCI and schematic design is updated

#### Resolution Notes

Removed PCIe J1 connector and enclosure cutouts; added MOD-BLE-PCB-ANT U11 BTLE module with 1Mb/s UART interface, capacitive touch pairing, status LED/buzzer signaling, Bluetooth runic logo on enclosure lid, and complete PCB/schematic integration.
