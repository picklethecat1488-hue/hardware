# 🟢 `[BUG-205]` Clicking "Code Review" opens wrong commit

- **Status**: `RESOLVED`

#### Description

When I select commit 947e55f5 and click the "Code Review" button, the "Code Review" page opens the CR for commit 67d3825c5f12d69c1c248ee505c346f7302fb9ac instead.

#### Resolution Notes

1. Resolved commit discrepancy in `DashboardServer` where `/review`, `/api/session`, and `/api/commits` were defaulting to the startup HEAD commit instead of honoring the requested `revisions` parameter.
2. Updated `_handle_serve_review_ui` and `/api/open_code_review` to dynamically build and bind the review session for the specific selected commit.
3. Updated `code_review.html.j2` client-side initialization to pass active URL query arguments to `/api/session` and `/api/commits` and auto-select the requested revision.
4. Verified with regression unit test `test_regression_bug_191_and_205_code_review_revisions_and_multi_commit` in `src/tests/test_dashboard.py`.
