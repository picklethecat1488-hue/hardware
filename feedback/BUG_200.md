#### Description

Multiple scrollbars are visible in the VCS diff view, when Split mode is selected. Screenshot attached. Please revise this UI to have a horizontal single scrollbar element at the bottom and enforce a maximum line length for files.

#### Resolution Notes

1. Removed per-line `overflow-x: auto` from `.diff-code-cell` in `src/provider/templates/diff_component.html.j2` which was generating independent horizontal scrollbars for every overflowing table row.
2. Replaced with single horizontal and vertical scrollbars on the `.diff-scroll-body` container, styled with the Quake HUD scrollbar theme.
3. Enforced a maximum line length (`MAX_LINE_LENGTH = 1000`) in `QuakeDiffEngine` with `truncateLine` to prevent unboundedly wide code lines from distorting the table layout.
4. Added regression unit test `test_regression_bug_200_diff_view_single_bottom_scrollbar_and_max_line_length` in `src/tests/test_dashboard.py`.
