# 🔴 `[BUG-194]` Separate group for LFS tracked files

- **UUID**: `88cdc854-15e0-4391-8323-9068645ea6cd`
- **ID**: `BUG-194`
- **Status**: `RESOLVED`
- **Severity**: `LOW`
- **Category**: `INFRASTRUCTURE`
- **Component**: `dashboard`
- **Created**: `2026-09-28 20:05:09 UTC`

#### Description

Group LFS tracked files under their own grouping element in the "Changed Files" column, and color them uniquely from normal files.

#### Resolution

1. Added `is_lfs: bool = False` to `WorkingTreeFileModel` in `src/model/vcs.py`.
2. Implemented `check_lfs_paths` in `GitEngine` (`src/provider/vcs/git_engine.py`) to query `.gitattributes` LFS filters via `git check-attr filter -- <paths>` and identify files under `attachments/`.
3. Populated `is_lfs` in `get_working_tree_files`, `_get_working_tree_files_simple`, and `get_changed_files`.
4. Enhanced HUD diff viewer UI in `src/provider/templates/diff_view.html.j2`:
   - Added distinct cyan styling (`.status-lfs`, `.lfs-file-item`, `#00e5ff`, `#38bdf8`) uniquely styling LFS files.
   - Added dedicated `📦 LFS Tracked Files` group sections to both working tree and commit file lists.
   - Added `LFS` status badge and integrated LFS indicators into the commit/amend modal dialog.
5. Added regression unit test `test_regression_bug_194_lfs_tracked_files_grouping_and_styling` in `src/tests/test_dashboard.py`.
