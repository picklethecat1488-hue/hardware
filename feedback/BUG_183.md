#### Description

We have open space on the board bw J1 and J14 to harden the design:
- Add isolation jumpers bw FTDI CBUS pins for NRST and BOOT0 to design, when jumpers are removed allow the system to boot normally
- Add BOOT0 override jumper to force a boot into ISP mode during the next POR
- Add reset button to force a system reset on U1
- Add isolation jumper for VBUS, allowing the system to run on battery power when charger is connected
- Add power good/enable LEDs for VBAT, VBUS, 3V3, audio amp, PERIPH_3V3, and U1
- Jumpers and LEDs should be clearly silkscreened and grouped into their own use-case regions
-New components should be added under a "Status and Overrides" schematic section
- Rerout: okay, but do not change any existing component placements!

#### Resolution

1. Added reset switch `SW1` (`SW_PUSH_SMD`), isolation jumpers `JP1` (NRST), `JP2` (BOOT0), `JP3` (VBUS), override jumper `JP4` (BOOT0 ISP) and status LEDs `D2..D7` with series resistors `R7..R12` to `src/projects/carrier_board/wiring.yaml`.
2. Created schematic sheet 17 "Status and Overrides" in `src/projects/carrier_board/pcb.yaml` with organized passive positions, avoiding collinear wire overlaps and label crossings.
3. Added silkscreen grouping boxes and descriptive labels in `src/projects/carrier_board/provider.py`.
4. Rerouted carrier board traces and vias using `JaxPCBRouter` without shifting any existing components.
5. Verified 0 KiCad DRC violations (`build/rpt/carrier_board-drc.rpt`), 0 unconnected pads, and added regression test `test_regression_bug_183_carrier_board_hardening`.
