#### Description

Clicking "Code Review", along with multiple commits selected, took me to a blank/empty code review page.

#### Resolution Notes

1. Added `get_review_session(revisions)` to `DashboardServer` in `src/provider/dashboard/server.py` to initialize or load a `ReviewSessionModel` tailored to all selected commits in the range.
2. Updated `/api/session` and `/api/commits` endpoints to parse `revisions` from query parameters or `Referer` headers, returning full `CommitInfoModel` metadata for each selected commit.
3. Updated `loadSession()` and `loadCommits()` in `src/provider/templates/code_review.html.j2` to forward `window.location.search` parameters to backend REST endpoints.
4. Added regression unit test `test_regression_bug_191_and_205_code_review_revisions_and_multi_commit` in `src/tests/test_dashboard.py`.
