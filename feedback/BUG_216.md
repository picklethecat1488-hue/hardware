2. Fixed `/api/version` in `DashboardServer` to return the integer `db_version` counter so client-side `pollForExternalUpdates()` detects changes, and updated `/api/next_bug_id` to return `{"next_id": ...}` matching client expectations.
3. Added file watch checks to `save_and_sync()`, `/api/exit`, and mutating requests in `do_POST` so changes on disk are merged before saving.
4. Protected `RESOLVED` bug states from regressions across `merge_databases()`, `scan_and_sync_feedback_dir()`, `_handle_save_bug()`, and `export_individual_bug()`, preventing unrefreshed UI form submissions or stale markdown exports from wiping resolution notes or reopening issues.
5. Added automated regression test `test_regression_bug_216_save_and_exit_preserves_resolved_bugs` in `src/tests/test_dashboard.py`.
