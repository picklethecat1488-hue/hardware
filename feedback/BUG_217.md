#### Description

Add horizontal and vertical resizers to text controls in the bug report page, and automatically increase the vertical size (up to a limit) of text controls as more information is filled in.

#### Resolution Notes

1. Added `resize: both !important;` to all `textarea` elements in `src/provider/templates/bug_report.html.j2`, with `min-width: 200px` and `max-width: 100%`, enabling bidirectional manual resizing.
2. Added `resize: horizontal;` to `input[type="text"]` elements with `min-width: 150px` and `max-width: 100%`.
3. Implemented `autoResizeTextarea(el, maxLimit=500)` in client-side JavaScript, calculating scroll height and dynamically adjusting element height up to a 500px limit, switching to scroll overflow when exceeding the ceiling.
4. Hooked global `input` event listener to dynamically expand textareas as information is entered, and hooked `loadActiveBug()`, `init()`, and `toggleExpandPanel()` to automatically adjust heights upon bug selection.
5. Added automated regression test `test_regression_bug_217_textarea_bidirectional_and_autoresize` in `src/tests/test_dashboard.py`.
