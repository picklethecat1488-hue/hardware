# 🟢 `[BUG-204]` pytestt should contain only critical testing

- **UUID**: `99dea2d9-0618-4e11-9f48-661da1741418`
- **ID**: `BUG-204`
- **Status**: `RESOLVED`
- **Severity**: `HIGH`
- **Category**: `PCB`
- **Created**: `2026-09-28 22:46:45 UTC`

#### Description

pytest should contain only critical testing for core scenarios. Right now, it is doing many unnecessary CAD boolean operations, mathematical models, and etc, that are not needed for core scenario testing. Please optimize the test plan and mark any non-critical tests as "slow".

#### Resolution

Optimized the test suite across core test modules to keep fast `pytest` lean and focused on critical regression and structural checks:
1. Marked resource-intensive CAD boolean checks, full CAM exports, KiCad DRC verification, and PyBullet fluid physics tests with `@pytest.mark.slow` in `src/projects/tests/test_cat_fountain.py`, `src/tests/test_bullet_fluid.py`, `src/tests/test_room.py`, `src/tests/test_pcb_export.py`, `src/tests/test_pcb_drc.py`, `src/tests/test_pcb_advanced.py`, and `src/projects/tests/test_carrier_board.py`.
2. Preserved core invariant validations in the fast test suite while deferring heavy shape intersections and manufacturing artifact generations to `pytest -m "slow"`.
3. Introduced regression unit test `test_regression_bug_204_fast_pytest_suite_timing_and_slow_markers` in `src/tests/test_pcb_advanced.py` to ensure slow markers are permanently retained on heavy integration suites.
