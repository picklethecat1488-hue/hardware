#### Resolution Notes

1. Replaced anonymous `_blank` window opening in `diff_view.html.j2` with named window targets (`hardware_bug_tracker`, `hardware_code_review`), ensuring browsers reuse existing tabs rather than spawning new tabs on every navigation or bug filing action.
2. Updated `saveAndExit` and dashboard return links in `bug_report.html.j2` and `code_review.html.j2` to detect `window.opener` and close the current tab while focusing the existing Diff Viewer dashboard tab (or targeting `hardware_vcs_diff_viewer`), preventing duplicate dashboard tab proliferation.
3. Added regression unit test `test_regression_bug_201_single_diff_viewer_and_bug_tabs_reuse` in `src/tests/test_dashboard.py`.
