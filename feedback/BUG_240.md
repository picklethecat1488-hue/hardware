#### Description

Some arguments to dashboard completely customize the behavior of the CLI command when specified, bypassing the web server startup so that they can print output to the console and exit. These arguments should be specified as subcommands, with subcommand groups created for optional behavior modifiers that can be used to customize them. Subcommands should also follow an action-topic syntax to make them easier to understand

#### Behavior Comparison

- **Expected**: python src/dashboard.py  --reviews
- **Actual**: python src/dashboard.py list-reviews

#### Resolution Notes

Added action-topic subcommands to dashboard.py CLI with backward compatibility for flags
