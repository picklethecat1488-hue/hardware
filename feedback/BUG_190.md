#### Description

When I click '⎇ ORIGIN/PR520', it does not take me to the opened PR in GitHub.

#### Resolution Notes

1. Added `get_branch_url` method to `GitEngine` to resolve remote and local branch names (including `origin/pr520`, `ORIGIN/PR520`, `pr-520`) to canonical GitHub PR URLs.
2. Rendered branch and tag badges in `src/provider/templates/diff_view.html.j2` as anchor tags (`<a href="..." target="_blank" rel="noopener noreferrer">`) rather than non-navigable spans, ensuring clicks are never blocked by browser popup blockers.
3. Updated `onBranchBadgeClick` JavaScript handler to correctly parse PR numbers from `origin/pr*` branch formats and fall back to GitHub branch tree links.
4. Added regression unit test `test_regression_bug_190_pr_branch_tags_clickable_links` in `src/tests/test_dashboard.py`.
