#### Description

- Allow vertical panels in the code review panel to be resized
- Give special UI formatting to LFS tracked files

#### Resolution Walkthrough

1. **Vertical Panel Resizing (`code_review.html.j2`)**:
   - Added draggable resizers `<div class="column-resizer" id="resizerCommits">` between `#paneCommits` and `#paneFiles`, and `<div class="column-resizer" id="resizerFiles">` between `#paneFiles` and `.pane-diff`.
   - Replaced fixed minimum widths on `.pane-header`, `.commits-list`, and `.files-list` with flexible bounds.
   - Added `initPanelResizers()` supporting mouse drag resizing and persistent width storage in `localStorage` (`codereview_commits_width`, `codereview_files_width`).
   - Integrated pane collapse/expand toggling to synchronize resizer visibility and restore saved widths.
2. **LFS UI Formatting**:
   - Added `.quake-badge-lfs` and `.lfs-file-item` styles in CSS.
   - Enhanced `renderFilesList()` to detect Git LFS tracked files (via `f.is_lfs` or attachment paths) and render `📦 LFS` badges with cyan accent styling.
   - Added `#activeFileLfs` badge in the diff view toolbar dynamically activated when viewing LFS assets.
   - Formatted binary diff cards for LFS assets with explicit Git LFS tracking notices.
   - Added `is_lfs: bool = False` to `FileDiffModel` and set `is_lfs` dynamically in `GitEngine.get_file_diff`.
3. **Regression Tests**:
   - Added `test_regression_bug_211_code_review_panel_resizing_and_lfs_styling` in `src/tests/test_dashboard.py`.
