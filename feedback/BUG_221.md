#### Resolution Notes

1. Updated `GitEngine.get_branches` in `src/provider/vcs/git_engine.py` to query both `refs/heads/` and `refs/remotes/`, and strip `refs/heads/` prefix directly from the full reference name rather than using ambiguous `%(refname:short)`, ensuring `refs/heads/main` resolves cleanly to `main` even when a colliding tag named `main` exists.
2. Included remote tracking branches (such as `origin/v3`, `origin/v4`, `origin/v5`) that do not yet have local branch counterparts, with automatic tracking branch checkout in `GitEngine.checkout_branch`.
3. Created local release branches `v1`, `v2`, `v3`, `v4`, `v5` pointing to their respective release tags and tracking upstream refs.
4. Updated branch classification and sorting in `src/provider/templates/diff_view.html.j2` so `main` is placed first, followed by release branches `v1..v6` sorted numerically in the `⭐ Main & Release Branches` section.
5. Added automated regression test `test_regression_bug_221_branches_missing_from_branch_viewer` in `src/tests/test_dashboard.py`.
