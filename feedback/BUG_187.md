# 🟢 `[BUG-187]` Allow file and commit panes to be collapsed in VS UI

- **Status**: `RESOLVED`
- **Severity**: `MEDIUM`

- **Created**: `2026-09-28 17:32:02 UTC`

#### Description

Allow the file and commit panes to be collapsed to the left side in the VCS UI, with an experience similar to the code_review tool.

#### Resolution

1. Updated workspace container `.app-workspace` from static 3-column CSS grid to flex layout (`gap: 10px; overflow: hidden;`).
2. Added `.pane-smartlog` and `.pane-files` with smooth transitions (`transition: width 0.2s ease, opacity 0.2s ease`) and `.collapsed` states (`width: 0 !important; margin-right: -10px !important; opacity: 0; pointer-events: none`).
3. Added `.pane-diff` flex-grow workstation to smoothly occupy all available remaining space when either or both side panes are collapsed.
4. Added Quake toolbar toggle buttons `#btnToggleSmartlog` and `#btnToggleFiles` in the VCS HUD toolbar, plus collapse buttons (`◀`) in the headers of both the Smartlog and Files panes.
5. Implemented `togglePane(pane)` state controller and keyboard shortcuts `[` (Smartlog) and `]` (Files) matching standard IDE / code review UX.
6. Verified with regression unit tests in `src/tests/test_dashboard.py`.
