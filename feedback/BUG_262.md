#### Description

Each project should output supplier files:
-gerbers.zip: contains .pcb .pcbdoc .cam .brd and gerber files
-bom_templates.zip: contains <PCB name>_bom.csv BOM list for each PCB
-centroid_files.zip: contains <PCB name>_pos.csv centroid list for each PCB
-assembly_files.zip: contains <PCB name>_top.png, <PCB name>_bottom.png top and bottom PCB textures for each PCB
The zip files should go under build/board

#### Resolution Notes

Added Builder.package_supplier_pcb_files to automatically package supplier zip archives under build/board and build/board/<project>: gerbers.zip (contains .pcb, .pcbdoc, .cam, .brd, and all gerber files), bom_templates.zip (contains <PCB name>_bom.csv for each PCB), centroid_files.zip (contains <PCB name>_pos.csv for each PCB), and assembly_files.zip (contains <PCB name>_top.png and <PCB name>_bottom.png textures for each PCB). Added regression test test_regression_bug_262_supplier_pcb_guidelines_zip_outputs.
