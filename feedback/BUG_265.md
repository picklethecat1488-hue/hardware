#### Description

Can we simplify the logging of tools long these lines-
-Only log what target got built to stdout
-Use structured logging to log individual file compilations to build/daemon.log
Example below

We could extrapolate this further to all tools. For example, in the new scheme view.py should only show the target being shown, and everything else would be output to daemon.log:

$ python src/view.py carrier_board/carrier_board:pcb
👁️ Showing carrier_board_carrier_board_pcb 
▶ + 
✔ Done Visualizing...

$ python src/view.py carrier_board/carrier_board:pcb
👁️ Showing carrier_board_carrier_board_pcb 
✔ Done Visualizing...

#### Behavior Comparison

- **Expected**: $ python src/build.py "carrier_board/*"
- **Actual**: $ python src/build.py "carrier_board/*"

#### Resolution Notes

Route individual file compilation logs to build/daemon.log via Logger.log structured logging, keeping stdout clean with only target compilation summaries and completion status.
