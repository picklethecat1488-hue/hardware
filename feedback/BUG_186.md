# 🔴 `[BUG-186]` Support git LFS tracking in dashboard

- **UUID**: `3650e51d-24a8-48cc-be1f-45e19c77fcdf`
- **ID**: `BUG-186`
- **Status**: `RESOLVED`
- **Severity**: `MEDIUM`
- **Category**: `INFRASTRUCTURE`
- **Component**: `diff_view, dashboard`
- **Created**: `2026-09-28 17:29:23 UTC`

#### Description

Move LFS tracking storage for bug report attachments from build/attachments to attachments/
Update the dashboard tool to track changes under attachments/ in LFS automatically when committing or amending changes

#### Resolution

1. Moved bug report attachments storage from `build/attachments/` to `attachments/` at the repository root.
2. Configured `.gitattributes` to automatically track `attachments/*` and `attachments/**` using Git LFS (`filter=lfs diff=lfs merge=lfs -text`).
3. Updated `BugReportServer` and `DashboardServer` to save new uploads to `attachments/` while retaining backward-compatible serving for both `/attachments/` and `/build/attachments/`.
4. Enhanced `GitEngine.commit_files` with `_ensure_lfs_tracking_for_attachments` to ensure Git LFS tracking is configured and `.gitattributes` is staged whenever files under `attachments/` are committed or amended.
5. Added regression unit tests `test_regression_bug_186_lfs_tracking_for_attachments` in `src/tests/test_dashboard.py` and `test_regression_bug_186_bug_report_server_attachments_dir` in `src/tests/test_bug_report.py`.
