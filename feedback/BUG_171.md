- Create a custom experience for agent feedback:

  - Add tags to commits showing bug status changes, and add a way to create or open bugs in the bug viewer tool

- Share the diff view code between the code review tool and the diff view tool

- Allow staged or untracked changes selected for a commit, or discarded
