# 🔴 `[BUG-184]` Pull power and GND off-sheet symbols to the sheet edge

- **UUID**: `d2471a2c-8190-47f5-bff7-ee6646a65093`
- **ID**: `BUG-184`
- **Status**: `RESOLVED`
- **Severity**: `MEDIUM`
- **Category**: `PCB`
- **Component**: `carrier_board`
- **Created**: `2026-09-28 17:26:35 UTC`

#### Description

We should refactor the schematic layout engine to pull the power off-sheet symbols (3V3, VBUS, etc) closer to the top of the sheet, and GND symbols closer to the bottom of the sheet, so they don't clutter signal line routing.

#### Resolution

1. Refactored power and GND off-sheet symbol rendering in `src/provider/schematic_diagram.py`:
   - Grouped and individual GND leads extend vertically downward toward the bottom sheet edge (`Y <= 50.0`, default `22.0` or `48.0` above title block).
   - Grouped and individual power rail symbols (`3V3`, `VBUS`, `VBAT`, `PERIPH_3V3`, etc.) extend vertically upward toward the top sheet margin (`Y >= 165.0`, default `176.0`).
   - Multiple power nets on the same side are horizontally offset to prevent overlapping vertical trunks.
   - Eliminated horizontal power stubs protruding into signal pin channels.
2. Updated pull-up top rail placement in `src/provider/schematic/passives.py` to align with the upper power rail margin.
3. Added regression unit test `test_regression_bug_184_power_and_gnd_symbols_pulled_to_sheet_edges` in `src/tests/test_pcb_advanced.py`.
